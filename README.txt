# STRM Downloader Modern - version corrigée

Projet Visual Studio .NET 8 WinForms.

Cette version contient bien :
- Program.cs avec Main()
- MainForm.cs
- STRM_Downloader_Modern.csproj

Fonctions :
- scan récursif des .strm sur un dossier local ou NAS
- recherche
- films / séries
- extraction de l'URL HTTP/HTTPS
- téléchargement MKV
- progression
- vitesse
- temps restant
- annulation
- suppression du fichier partiel en cas d'erreur/annulation

Ouvre `STRM_Downloader_Modern.sln` dans Visual Studio 2022.
